# LU Software Development Club - Game Development Team (2024)

We made this game to learn about the basics of using **SFML** for game development with **C++**.

Over the course of a semester, our group got together every week to learn more about SFML and progress our game just a little further. We met up for about 1 hour a day, once a week, so we didn't have much time, but we made the most of it, eventually getting our game loop fully completed by the end.

To build this game for yourself, simply clone the repository, open it in Visual Studio, and you're ready to go!
